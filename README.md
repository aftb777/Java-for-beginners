Whether you're a student, hobbyist, or professional looking to brush up on Java basics, you'll find these resources useful.

## Getting Started

### Prerequisites

- [Java JDK](https://www.oracle.com/java/technologies/downloads/) (version 8 or later)
- A text editor or IDE (e.g., VSCode, IntelliJ IDEA, Eclipse)
- Basic computer skills

### Installation

1. **Clone the repository**

    ```bash
    git clone https://github.com/aftb777/Java-for-beginners.git
    cd Java-for-beginners
    ```

2. **Set up your Java environment**  
   Ensure your `JAVA_HOME` is configured, and Java is accessible via terminal/command prompt:

    ```bash
    java -version
    ```

## How to Use

- Browse the `src/basics/` folder to start with simple programs.
- Try out exercises in `src/exercises/` and check your answers in `src/solutions/`.
- Review explanations in the `notes/` directory.
- Compile and run Java programs using:
    ```bash
    javac FileName.java
    java FileName
    ```
